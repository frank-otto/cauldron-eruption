# Sounds – sources & licenses (Cauldron Eruption)

All sounds are real recordings released under **CC0 1.0** (https://creativecommons.org/publicdomain/zero/1.0/). No synthesizer, no oscillators, no beeps. They were trimmed, faded, made mono, pitched down and low-passed where needed (deep and crunchy, never shrill) and loudness-matched; looping beds got a crossfaded seam. `tools/build.mjs` embeds them as base64 into `js/sounds-src.js`, so the game also runs via `file://`. The kitchen echo is a generated convolution impulse (processing only). Credit is not required for CC0 and is given voluntarily, by source ID only. Each new Freesound page was checked for the CC0 1.0 license.
